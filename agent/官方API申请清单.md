# 官方 API 申请清单（合规路径）

> 目标：把「人工导出 CSV」升级成「官方接口自动拉取」。
> 现状：两个平台的**内容数据**都有官方接口，但都要**资质 + 应用审核**；
> **私信咨询数、报名意向人数**没有任何平台会开放，必须人工补录（这不影响自动化的价值）。

---

## 一、抖音开放平台（内容数据其实能拿）

**入口**：https://developer.open-douyin.com

| 步骤 | 要做的事 | 门槛/耗时 |
|---|---|---|
| 1 | 注册开发者，创建「网站/小程序/移动应用」 | 营业执照（个人开发者权限很有限） |
| 2 | 申请「数据开放」相关能力：`video.list`（作品列表）、`video.data`（作品数据） | 企业主体 + 应用审核，1–5 个工作日 |
| 3 | 账号绑定：把「不止攀岩」抖音号授权给应用 | 需该账号管理员扫码 |
| 4 | 拿 access_token → 调接口 | token 有效期短，需 refresh |

**能拿到的**：作品 ID、标题、发布时间、播放/点赞/评论/收藏/分享（口径与创作者中心一致但不完全等于）。
**拿不到的**：私信数、粉丝明细（粉丝总量部分能力开放）、报名意向。

> ⚠️ 现实提醒：抖音对「数据类」能力审核偏严，个体工作室常被拒。
> 所以本方案的默认链路是「官方后台导出 → CSV → 飞书」，接口作为二期升级项。

---

## 二、小红书开放平台

**入口**：https://open.xiaohongshu.com

| 步骤 | 要做的事 | 门槛/耗时 |
|---|---|---|
| 1 | 注册服务商/商家开发者 | 一般要企业资质或服务商身份 |
| 2 | 申请「笔记数据」类接口 | 审核周期更长，个人账号基本拿不到 |
| 3 | 绑定「不止攀岩」专业号 | 专业号 + 管理员扫码 |

**能拿到的**（若通过）：笔记列表、笔记基础数据（观看/点赞/评论/收藏/分享）。
**拿不到的**：私信、咨询、报名意向。

> 小红书官方几乎没有对第三方开放内容数据 API 的先例。**建议不把希望放在这里**，
> 用「创作中心导出 / 网页表格复制」作为长期方案，成本低且完全合规。

---

## 三、合规红线（不要碰）

| ❌ 不能做 | 原因 |
|---|---|
| 爬虫抓创作者中心/后台 | 违反平台用户协议，账号有封禁风险 |
| 抓包 App 私有接口 | 同上，且接口随时变 |
| 买第三方「数据接口」 | 多数是爬虫二次倒卖，连带责任 |
| 自动登录 + 模拟点击抓数据 | 属于自动化访问，平台明令禁止 |

**允许的**：平台自己提供的导出、开放平台官方 API、平台提供的「数据看板截图/人工记录」。

---

## 四、私信/咨询/报名意向怎么解决（人工补录，但很轻）

飞书表里预留了这几个字段，每天花 30 秒填：

| 字段 | 怎么填 |
|---|---|
| 私信咨询数 | 抖音/小红书私信里当天**新增**的咨询条数（合并算一个数也行） |
| 咨询来源 | 单选：抖音 / 小红书 / 朋友介绍 / 其他 |
| 报名意向人数 | 明确说要报名/问价格的人（不含只问"多少钱"就走的） |
| 成交/定金 | 收了定金的单数（和课程报名台账联动） |

> 建议做成**手机端 30 秒表单**（飞书表单），填完直接进多维表格同一张表，
> 比在电脑上改表格快得多。

## 五、二期升级路线（接口下来之后）

1. 先拿抖音 `video.list` + `video.data`，替换 `sources/api_douyin.py` 里的 TODO
2. 小红书保持导出（成本最低）
3. `config.json` 里把 `source.mode` 从 `export` 改成 `api`（两个平台可以混用）
4. 私信/咨询仍然人工补录 —— 这部分永远不会自动化，也不值得自动化

代码里已经留好位置：
```
sources/api_douyin.py   ← 抖音接口适配器（现在是骨架，填 token 即可用）
sources/api_xhs.py      ← 小红书接口适配器（大概率用不上）
```
