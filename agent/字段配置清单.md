# 飞书多维表格 · 字段配置清单

在工作台 Base 里新建 **2 张表**（不要往排班表/装备表里加列）。

字段类型编号（飞书 API 用）：1 文本 2 数字 3 单选 4 多选 5 日期 7 复选框 15 超链接 17 附件 20 公式 1001 创建时间

---

## 表① 新媒体-素材明细（一条素材一行）

| # | 字段名 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| 1 | 素材ID | 文本(1) | ✅ | `平台_内容ID`，例如 `douyin_7699028474867223731`；**去重键**，同 ID 不重复插入 |
| 2 | 平台 | 单选(3) | ✅ | 选项：`抖音` / `小红书` |
| 3 | 发布日期 | 日期(5) | ✅ | 素材发布日，按日期显示 `yyyy/MM/dd` |
| 4 | 标题/文案 | 多行文本(1) | ✅ | 抖音标题或小红书笔记标题 |
| 5 | 素材链接 | 超链接(15) | ✅ | 抖音作品页或小红书笔记页 URL |
| 6 | 内容ID | 文本(1) | ✅ | 平台自己的作品 ID（抖音 aweme_id / 小红书 note_id） |
| 7 | 内容类型 | 单选(3) | ⬜ | `视频` / `图文`（导出里没有就给空） |
| 8 | 播放/浏览量 | 数字(2) | ✅ | 抖音=播放量，小红书=观看数；统一叫「曝光」 |
| 9 | 点赞 | 数字(2) | ✅ | |
| 10 | 评论 | 数字(2) | ✅ | |
| 11 | 收藏 | 数字(2) | ✅ | 抖音「收藏」/ 小红书「收藏」 |
| 12 | 分享/转发 | 数字(2) | ✅ | 抖音「分享」/ 小红书「分享」 |
| 13 | 新增粉丝 | 数字(2) | ⬜ | 导出通常没有；只有小红书部分导出/抖音吸粉量才有值 |
| 14 | 互动合计 | 数字(2) | 公式 | `点赞+评论+收藏+分享`，或直接写数字 |
| 15 | 封面 | 附件(17) | ⬜ | 有封面图就传，没有留空 |
| 16 | 数据来源 | 单选(3) | ✅ | `后台导出` / `官方API` / `人工补录` |
| 17 | 采集时间 | 日期(5) | ✅ | 脚本运行时间 |
| 18 | 异常状态 | 文本(1) | ⬜ | 仅异常时写，如 `解析失败：缺播放列` |
| 19 | 备注 | 文本(1) | ⬜ | 人工补充 |

**去重**：`素材ID` 建唯一性（用「数据校验」或脚本先查后插）。脚本默认「当天已存在则跳过」。

## 建表小贴士

1. **日期字段**先建好「日期格式 = yyyy/MM/dd」，脚本写入的是毫秒时间戳，飞书会自动显示成日期。
2. **单选字段**不要开「允许添加新选项」，否则拼错会多出一堆脏选项；脚本只写上面列出的固定值。
3. **数字字段**关掉千分位以外的小数（全部整数）。
4. 两张表都建议加「视图」：
   - 素材明细：视图 `今日`（发布日期=今天）、`按平台`（按平台分组）
   - 每日汇总：视图 `近7天`（日期在最近 7 天内）
5. `最佳素材`、`互动合计` 也可以改成飞书公式，但脚本里算好更稳（公式改列后 API 写入会报错）。
