# 小红书后台导出说明（每天 2 分钟）

> 只走平台自带数据页 + 官方导出，不做爬虫。

## 一、能从哪里拿数据

| 入口 | 能拿到什么 | 适合 |
|---|---|---|
| 创作中心 → 数据中心 → **笔记数据** | 每篇笔记：观看、点赞、评论、收藏、分享 | ✅ 每日主数据 |
| 创作中心 → 数据中心 → **粉丝数据** | 粉丝总数、新增/取关 | ✅ 每日汇总用 |
| 手机 App → 我 → 创作中心 | 同上（手机看，不方便导出） | 备用 |

> 打开：https://creator.xiaohongshu.com →「数据中心」→「笔记数据」→ 选日期 → 导出/截取。

## 二、导出步骤

1. 浏览器登录 https://creator.xiaohongshu.com
2. 左侧「数据中心」→「笔记数据」
3. 时间选「昨天」或「近 7 天」
4. 有「导出」按钮就点导出；**没有导出按钮时**用下面两种办法：
   - 网页表格直接复制粘贴到 Excel，另存为 CSV（列名保持原样即可，脚本会模糊匹配）
   - 手工记到 `data/inbox/xhs_export_YYYY-MM-DD.csv`，最少三列：`笔记ID,发布时间,观看量`
5. 文件命名 **`xhs_export_YYYY-MM-DD.csv`**，放到：

```
新媒体数据Agent\data\inbox\
```

## 三、字段对应

| 小红书页面上的叫法 | 脚本认的列名（模糊匹配） | 必填 |
|---|---|---|
| 笔记标题 / 标题 | `标题`、`笔记标题` | ✅ |
| 发布时间 | `发布时间`、`时间` | ✅ |
| 观看量 / 浏览量 / 曝光 | `观看量`、`浏览量`、`播放量` | ✅ |
| 点赞 | `点赞`、`赞` | ✅ |
| 评论 | `评论` | ✅ |
| 收藏 | `收藏` | ⬜ |
| 分享 | `分享`、`转发` | ⬜ |
| 笔记 ID / 链接 | `笔记ID`、`链接` | ⬜（没 ID 时用标题哈希生成） |

## 四、容易踩的坑

1. **小红书没有「播放量」，叫「观看量」** —— 两个都认，别自己改成"播放"以外的怪名字。
2. **收藏/分享常常合并显示**（如「赞藏 120」）—— 导出里出现合并列时，脚本按赞 0.75 / 藏 0.25 估算，并在备注里说明；能有分开的列就优先用分开的。
3. **笔记 ID 在网页 URL 里**：`https://www.xiaohongshu.com/explore/<笔记ID>`，复制粘贴时别把参数带上。
4. 小红书粉丝数不在笔记导出里，要单独记（见「每日汇总」的 `新增粉丝` 人工补录）。

## 五、如果这一天没发笔记

`data/inbox/` 里不用放文件，脚本会自动记 0 条并写「今天没有新发布素材」。
