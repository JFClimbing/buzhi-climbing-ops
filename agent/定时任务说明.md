# 定时任务说明（每天 08:30 自动跑）

三种方式，任选一种。推荐 **方式 A（Windows 计划任务）**，不依赖任何第三方服务。

---

## 方式 A：Windows 计划任务（推荐，本机已装好脚本）

### A1. 一键创建（管理员 PowerShell）

```powershell
cd "C:\Users\JF\Desktop\运营\工作室运营\新媒体数据Agent"
powershell -ExecutionPolicy Bypass -File .\register_task.ps1
```

跑完用 `schtasks /Query /TN "不止攀岩-新媒体日报"` 确认。

### A2. 手动在「任务计划程序」里建

1. 开始菜单搜「任务计划程序」→ 创建基本任务
2. 名称：`不止攀岩-新媒体日报`
3. 触发器：每天 08:30（想 9 点就 09:00）
4. 操作：启动程序
   - 程序：`C:\Users\JF\AppData\Local\Programs\…\python.exe`（你的 Python 绝对路径）
   - 参数：`daily_job.py`
   - 起始于：`C:\Users\JF\Desktop\运营\工作室运营\新媒体数据Agent`
5. 勾「不管用户是否登录都要运行」+「使用最高权限运行」
6. 条件里取消「只在交流电源时启动」

### A3. 最简单：双击

`启动每日任务.bat` —— 手动/半自动用这个。

> **注意**：脚本默认拉「昨天」（`report_date_offset: 1`）。
> 08:30 跑的时候，前一天的完整数据已经出来了，导出文件放好即可。

---

## 方式 B：飞书自动化（不占本机）

飞书多维表格自带「自动化」：
1. 表格右上角「自动化」→ 新建流程
2. 触发：「定时触发」→ 每天 09:00
3. 执行：「发送 HTTP 请求」→ 调本机/公网的 `/api/brief?period=daily`
4. 下一步「新增记录」把返回的数值写进每日汇总表

⚠️ 前提：接口必须**能被飞书访问到**。本机 `127.0.0.1:8848` 飞书访问不到，需要：
- 内网穿透（cpolar / frp / 花生壳），或
- 把 `api_server.py` 部署到一台有公网的服务器，或
- 改用方式 A（本机跑，推给飞书）

---

## 方式 C：手动 + 提醒

最省事：每天收到手机日历提醒 → 双击 `启动每日任务.bat`。
适合前期人少、数据量小的时候。

## 每天要做的三件事（1 分钟）

| 顺序 | 动作 | 位置 |
|---|---|---|
| 1 | 抖音创作者中心导出作品数据 → 改名 `douyin_export_YYYY-MM-DD.csv` | `data/inbox/` |
| 2 | 小红书创作中心导出/复制笔记数据 → 改名 `xhs_export_YYYY-MM-DD.csv` | `data/inbox/` |
| 3 | 双击 `启动每日任务.bat`（或等 08:30 自动跑） | 本目录 |

跑完看两个地方：
- `data/logs/<日期>.log` —— 有没有报错
- 飞书表「新媒体-每日汇总」—— 当天那行是否新增

## 失败怎么办

脚本不会中断其他表，只把自己这一行标成异常：

| 运行状态 | 含义 | 处理 |
|---|---|---|
| 正常 | 全部写入成功 | 无需操作 |
| 部分异常 | 某平台解析/写入失败，另一个平台已写 | 看日志里 `⚠️` 行，补数据后手动重跑当天 |
| 异常 | 全部失败（多为飞书 token 过期或网络） | 检查 `config.json` 的 app_id/app_secret；重跑 |

手动重跑指定日期：

```powershell
python daily_job.py --date 2026-11-17
```

先看会写什么不实际写（dry-run）：

```powershell
python daily_job.py --dry-run --date 2026-11-17
```

## 凭证怎么配

把 `config.example.json` 复制成 `config.json`，填入：

| 字段 | 从哪拿 |
|---|---|
| `feishu.app_id` / `app_secret` | 飞书开放平台 → 创建企业自建应用 → 凭证与基础信息 |
| `feishu.app_token` | 多维表格 URL 里 `/base/<app_token>` 那一段 |
| `feishu.table_material` | 素材明细表 ID（URL 里 `table=tblXXXX`） |
| `feishu.table_daily` | 每日汇总表 ID |

应用需要开通权限：`bitable:app`（读写多维表格）。加完权限要**发布版本并通过审核**才生效。
