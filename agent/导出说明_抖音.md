# 抖音后台导出说明（每天 2 分钟）

> 只走平台自带导出，不做任何爬虫。

## 一、导出步骤（电脑端）

1. 浏览器打开 https://creator.douyin.com （已登录状态）
2. 左侧「数据中心」→「作品数据」/「投稿列表」
3. 右上角选时间范围（建议「昨天」或「近 7 天」）
4. 点「导出」/「下载」，得到 `作品数据.xlsx` 或 `.csv`
5. 把文件改名成 **`douyin_export_YYYY-MM-DD.csv`**，丢进：

```
新媒体数据Agent\data\inbox\
```

> Excel 打开后「另存为 CSV UTF-8」更稳；脚本也支持 `.xlsx`？——本版只解析 `.csv` / `.json`，
> 如果是 xlsx，用 Excel 另存为 CSV 即可（或用 WPS 导出）。

## 二、导出时必须勾的列

| 列名（可能叫法） | 是否必须 |
|---|---|
| 作品ID / 视频ID | ✅ |
| 发布时间 | ✅ |
| 作品描述 / 标题 | ✅ |
| 播放量 | ✅ |
| 点赞量 | ✅ |
| 评论量 | ✅ |
| 收藏量 | ⬜（没有按 0 处理） |
| 分享量 | ⬜（没有按 0 处理） |
| 吸粉量 | ⬜（很多导出没有，留空） |
| 作品类型（视频/图文） | ⬜ |
| 作品链接 | ⬜（脚本会自己拼） |

## 三、账号级数据（粉丝数、总获赞）

在创作者中心首页能看到「粉丝总数 / 获赞总数」，导出里一般没有：
- 每天手工记一下，填到飞书「新媒体-每日汇总」的 `新增粉丝`（如果不接 API）
- 或者等官方 API 权限下来后自动取

## 四、没有导出功能时

手机端抖音创作者服务中心 → 数据 → 右上角「…」→ 导出（部分账号有这个入口）。
如果确实导不出来，就把 `data/inbox/` 里放一个**手抄的简易 CSV**，最少三列：
`作品ID,发布时间,播放量` —— 脚本照样能跑，其他字段按 0。
