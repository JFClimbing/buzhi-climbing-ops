# 字段映射说明（平台导出 → 飞书字段）

三列：**必填** ✅ = 没有就整条不写；**可选** ⬜ = 有就写；**人工** = 平台给不了，靠人填。

| 点赞 | 点赞量 | ✅ | |

## 三、平台给不了的字段（人工/其他系统）

| 飞书字段 | 来源 | 说明 |
|---|---|---|
| 私信咨询数 | **人工** | 抖音：企业号「消息」；小红书：专业号「私信」。前台每天填一个数 |
| 咨询来源 | **人工** | 多选，通常一天里两个平台都有 |
| 报名意向人数 | **人工** / 课程报名台账 | 与报名台账联动：台账里当天新增「意向」状态的行数 |
| 新增粉丝（账号级） | 平台后台首页 | 抖音：粉丝数；小红书：专业号中心。可每天人工填，或接官方 API 后自动 |

**为什么不做自动**：这三个字段都在「客服/私信/线索」后台，官方开放接口没有对个人号开放；
模拟点击登录后台属于违规抓取，本方案明确不做。

## 四、必填 / 可选 汇总（给写代码的人看）

**素材行最少要有这 8 个字段**，否则这条不写：
`素材ID、平台、发布日期、标题/文案、播放/浏览量、点赞、评论、数据来源`

**可选**：内容类型、封面、新增粉丝、分享、收藏、异常状态、备注

**汇总行最少要有这 5 个**：
`日期、平台范围、内容条数、总曝光、每日小结`

**人工项**：私信咨询数、咨询来源、报名意向人数、账号级新增粉丝

## 五、口径提醒（日报会被追问的点）

1. **曝光是累计值**：每天抓到的播放量是「这条内容截至今天的累计」，不是当天新增。
   所以「每日总曝光」= 当天**新发布内容**的累计播放 + 0；老内容的长尾增量需要两次快照相减（方案里预留了 `snapshots/` 目录，后续可做增量）。
2. **互动合计** = 点赞 + 评论 + 收藏 + 分享（不含播放）。
3. **咨询转化率** = 私信咨询数 / 总曝光，量级很小（万分之一级），日报里用「每万次曝光几个咨询」更好读。
4. 抖音「吸粉量」是发布以来累计，不是当天；小红书同理。账号级「新增粉丝」要用后台的「粉丝净增」。
